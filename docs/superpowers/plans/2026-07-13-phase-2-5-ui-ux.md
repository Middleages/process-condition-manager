# Phase 2.5 UI/UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 승인된 A2/V1/P1/W1/M1/S1-C를 기존 backend와 Phase 2 편집 계약을 바꾸지 않고 운영 가능한 전체 화면 구조와 디자인 시스템으로 구현한다.

**Architecture:** React Router를 data router로 전환해 일반 App Shell과 조건표 Focus Shell을 route 경계에서 분리하고, 각 화면의 복원 가능한 상태는 feature-local URL helper가 소유한다. TanStack Query는 server state, URL은 entity/filter/step, component state는 미저장 draft만 소유하며, 조건표의 `useSheetEditing`과 Glide adapter는 그대로 유지한다.

**Tech Stack:** React 18.3, React Router 7.1, TanStack Query 5, Zustand 5, Tailwind CSS 4, Glide Data Grid 6, TypeScript 5.7, Vitest 4 (`node` environment)

## Global Constraints

- 디자인 정본은 [`DESIGN.md`](../../../DESIGN.md), 상세 계약은 [`2026-07-13-phase-2-5-ui-ux-design.md`](../specs/2026-07-13-phase-2-5-ui-ux-design.md)다.
- backend, API schema, `frontend/package.json`, `frontend/package-lock.json`을 변경하지 않는다.
- 새 dependency, 외부 font, icon library를 추가하지 않는다. 이미 설치된 Lucide만 사용한다.
- Phase 2 persistence/domain/lock/autosave, dirty store, write queue, paste apply, condition/POR API 정책을 변경하지 않는다.
- 일반 App Header는 52px, 조건표 Focus Header는 40px다. 전역 sidebar와 `max-w-6xl`을 두지 않는다.
- Focus Shell은 `100dvh`와 `minmax(0, 1fr)`를 사용하고 body-level 이중 scroll을 만들지 않는다.
- 색 token은 Ink `#172F35`, Brand strong `#0F766E`, Brand accent `#14B8A6`, Canvas `#F4F7F8`, Surface `#FFFFFF`, Border subtle `#D7E1E5`, Control border `#81979E`, Muted `#52656A`다.
- light surface focus는 `#0F766E`, Ink header focus는 `#14B8A6` 또는 white inverse token을 사용한다.
- 프로젝트 목록은 현재 API 필드와 ID 내림차순만 사용한다. total, 수정일, owner, list lock, client-side sort를 만들지 않는다.
- 현재 project status는 `draft`뿐이다. 의미 없는 status control과 미래 status badge를 렌더링하지 않는다.
- 파라미터 query/category/type/active filter는 client-side다. server에는 `include_inactive`만 전달한다.
- Parameter nullable clear와 choice PATCH→PUT atomicity를 거짓 성공으로 숨기지 않는다. Backend 수정은 이 계획의 범위가 아니다.
- S1-C는 content가 없으면 DOM과 높이가 0인 host만 제공한다. Validation/history/comment data와 tile UI는 구현하지 않는다.
- Vitest는 DOM interaction 환경이 아니다. pure/API/view-model test는 자동화하고 focus/dialog/route/rendered grid는 browser evidence로 검증한다.
- UI를 렌더링해 수정하는 각 iteration은 다음 edit 전에 `$visual-verdict`를 실행하고 verdict JSON을 `.omx/state/phase-2-5/ralph-progress.json`에 기록한다.
- 모든 commit은 Lore trailer를 포함한다.

- [ ] **Step 3: Implement the native modal contract**

`ModalSurface` requirements:

```ts
export interface ModalSurfaceProps {
  open: boolean
  title: string
  variant: 'dialog' | 'drawer'
  onRequestClose: (reason: ModalCloseReason) => void
  initialFocusRef?: React.RefObject<HTMLElement>
  fallbackFocusRef?: React.RefObject<HTMLElement>
  children: React.ReactNode
  footer?: React.ReactNode
}
```

On `open=true`, capture `document.activeElement`, call `showModal()`, then focus `initialFocusRef` or the `tabIndex={-1}` title. Handle native `cancel` by `preventDefault()` and call `onRequestClose('escape')`. A backdrop pointer event calls `onRequestClose('backdrop')`. When closed, call `dialog.close()` and focus the captured trigger; if it is disconnected, focus `fallbackFocusRef`. Native `showModal()` supplies background inertness and focus containment without a dependency. Drawer is right-aligned at 420–480px, max 40vw, and full-width below 1024px.

`useUnsavedChanges` uses data-router `useBlocker` plus `useBeforeUnload`. On a blocked navigation, show the supplied Korean confirmation once, then call `blocker.proceed()` or `blocker.reset()`.
