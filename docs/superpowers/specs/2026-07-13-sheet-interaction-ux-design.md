# 조건표 편집 상호작용 개선 설계

## 배경

수동 QA에서 붙여넣기 대상 셀의 색상은 바뀌지만 값과 적용 동작이 보이지 않았고, 조건 행
관리 진입 방법과 choice 셀 활성화 방식도 발견하기 어려웠다. 범위 복사는 Glide가 이미
지원하지만 화면에 안내나 명시적 동작이 없다.

## 결정

붙여넣기는 기존의 안전한 **미리보기 → 적용/취소** 단계를 유지한다. 즉시 저장은 빠르지만
대량 범위의 타입 오류와 잘림을 확인할 기회를 없애므로 채택하지 않는다. 별도 모달 방식은
표와 대상 셀을 동시에 비교하기 어려워 채택하지 않는다.

## 화면과 상호작용

### 붙여넣기

- `Ctrl+V` 후 유효한 값과 불일치 값을 대상 셀 안에 즉시 미리보기한다.
- 유효 셀은 녹색, 불일치 셀은 적색 배경을 유지한다.
- 적용 건수, 오류, 잘림, `적용`/`취소`를 담은 패널을 그리드 바로 위에 표시한다.
- `적용` 전에는 서버 스냅샷과 dirty store를 바꾸지 않는다.
- 적용은 기존 session write queue와 `origin=paste` 저장 경로를 그대로 사용한다.

### 조건 행 관리

- 조건 행 관리 바를 그리드 바로 위에 항상 배치한다(잠금 보유 시).
- “왼쪽 Layer 또는 조건 셀을 선택”하라는 안내와 현재 선택된 행을 함께 표시한다.
- 빈 행 추가, 복제, 삭제 버튼은 행 선택 전에는 비활성화한다.
- POR 헤더/도구 설명에 빈 원을 클릭하면 POR가 이양된다는 안내를 제공한다.

### Choice 편집

- choice 셀에만 `single-click` 활성화 동작을 지정한다.
- 텍스트/숫자 셀과 행 식별 셀의 기존 선택·편집 동작은 바꾸지 않는다.
- 첫 클릭으로 네이티브 select overlay를 열고, 다음 클릭으로 값을 선택한다.

### 범위 복사

- 기존 `Ctrl+C` 범위 복사를 유지하고 상단에 `선택 영역 복사` 버튼을 추가한다.
- 버튼은 Glide의 현재 selection을 그대로 복사하며 `copyData`를 TSV로 사용한다.
- 복사한 범위는 같은 조건표 또는 다른 스프레드시트에 붙여넣을 수 있다.
- 복사 버튼을 위해 그리드 어댑터 핸들에 `copySelection()`만 추가하며 Glide 타입은 경계 밖으로
  노출하지 않는다.

## 오류와 상태

- 복사할 선택 영역이 없거나 브라우저가 클립보드를 거부하면 짧은 화면 메시지를 표시한다.
- 붙여넣기 불일치 값은 미리보기만 하고 적용 대상에서는 제외한다.
- 읽기 전용과 즉시 쓰기 진행 중에는 붙여넣기/조건 작업을 시작하지 않는다.

## 검증

- 스테이징 값이 서버 값 대신 미리보기에 사용되고 취소 시 원래 값으로 돌아가는 순수 테스트
- choice 셀에만 single-click 활성화가 지정되는 테스트
- copy 핸들이 Glide `copy` 이벤트를 전달하는 어댑터 확인
- 기존 붙여넣기 매핑·자동저장·조건 API 회귀 테스트
- 실제 브라우저에서 Excel 10×20 붙여넣기, 적용/취소, 같은 표 안의 범위 복사→붙여넣기,
  choice 첫 클릭, 조건 행 선택/복제/삭제를 수동 확인

## 범위 제외

- 즉시 붙여넣기 저장
- 우클릭 컨텍스트 메뉴
- 다중 조건 행 일괄 추가/삭제
- 사용자 정의 클립보드 형식 또는 서식 복사
- 새 외부 의존성
