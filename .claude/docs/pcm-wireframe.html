프론트엔드 상태 관리 구조

상태저장 위치설명
columnMeta전역 (Zustand/Redux)컬럼 메타데이터. 앱 초기화 시 1회 로딩. 카테고리별 그룹핑, display_name, 검증 규칙 포함
conditionData페이지 로컬 상태현재 프로젝트의 전체 조건표 데이터 (layers 배열). API 응답 그대로 보관
dirtyCells페이지 로컬 상태편집 후 아직 저장하지 않은 변경사항. Map<projectLayerId, Record<string, any>>
validationErrors페이지 로컬 상태현재 검증 오류 목록. 프론트 검증 + 백엔드 검증 결과 병합
activeCategory페이지 로컬 상태현재 선택된 카테고리 탭 코드 ('SP', 'SC', ...)
activeLayerId페이지 로컬 상태현재 선택된 레이어 ID (네비게이션 패널 연동)
