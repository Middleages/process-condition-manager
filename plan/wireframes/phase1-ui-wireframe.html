동작 메모 — Sheet Editor PoC

  1. 카테고리 탭 교정: 이전 버전의 Photo/Etch 탭은 layer 유형과 혼동 — 파라미터 카테고리는 레지스트리 관리 항목(SP/SC/OVL/DEV…)이며 탭은 동적 생성된다 (P1-D4). 컬럼 그룹 헤더도 같은 카테고리 기준.
  2. 빈 셀 의미 교정: "–"는 readonly가 아니라 편집 가능한 빈 값. layer 유형별 파라미터 적용성 개념은 도입하지 않음 (P2-D3) — 필요해지면 검증 규칙(Phase 3)으로 처리.
  3. 셀 상태 5종(기본/선택/dirty/staging/오류)을 범례로 고정 — 그리드 어댑터의 셀 상태 표시 계약과 1:1 대응.
  4. Paste staging: 붙여넣기는 즉시 반영이 아니라 staging(점선) → 타입 검사 → 적용/취소. 적용 시 dirty로 전환.
  5. 비보유자 화면(Phase 2): 상단에 "김공정 님이 편집 중 — 읽기 전용" 배너 + 편집/저장/붙여넣기 비활성.
  6. 이 화면은 그리드 PoC(phase-1-tasks T7) 검증 대상 — 실제 그리드는 Glide Data Grid vs RevoGrid PoC 결과로 확정.
